## 2. 通用完成定义

1. 用户可见文案同时提供 `zh-CN` 和 `en-US`。
2. 新增算法与状态转换覆盖成功、非法输入和边界测试。
3. ZIP、路径、兼容性、签名和权限由 Rust Host 独立校验。
4. 未签名插件允许安装，但确认页和已安装列表均持续显示风险。
5. 无未说明的 lint、类型、测试、构建或 clippy 失败。
6. 设计、架构、任务和里程碑状态同步更新。

## 3. 已完成基线

### M0：工程基线

- pnpm workspace、Tauri 2、React、TypeScript、Vite 和 Rust workspace。
- ESLint、Prettier、Vitest、React Testing Library、Rust test、Playwright 和 CI matrix。
- 版本同步、Changelog 与跨平台产物命名。

### M1：Shell 与平台骨架

- App Shell、语义 token、深浅主题、命令面板和响应式布局。
- `i18next + react-i18next`、中英文 key 检查、设置持久化。
- Plugin SDK、IPC envelope、Command Gateway、SQLite settings 和 revision。

### M2：插件分发基础

- manifest、Plugin API、包解析、checksum 和 Ed25519 验证。
- 安全解包、staging、原子安装、启停、回退、卸载和恢复。
- SQLite 插件、版本、授权和事件记录。
- 隔离 WebView、运行时身份、ready/failure、scoped settings 和剪贴板网关。

M2 中的在线目录和专用 `.devbox-plugin` 入口已在 M3 调整中移除；保留可复用的安全校验、事务和运行时隔离能力。

## 5. M3 验收清单

- [x] 左侧是分类/功能二级树，无工具/插件中间切换按钮。
- [x] JSON、Timestamp、Encoding、UUID/Hash 是内置功能。
- [x] 可同时打开多个 Tab；同功能只出现一次；可关闭和拖动排序。
- [x] 关闭插件 Tab 会销毁对应 child WebView；插件不打开独立窗口。
- [x] 重启后不恢复上次 Tab。
- [x] 语言切换只在设置页，中文和英文文案完整。
- [x] 插件管理只有 Installed 和 Add ZIP Plugin，无 Online。
- [x] 未签名 ZIP 在警告后可安装，安装后持续显示警告。
- [x] 非 ZIP、恶意路径、超限、不兼容、无效签名和篡改包被拒绝。
- [x] `devbox-tools` 已迁移并以可恢复方式删除。
- [x] `pnpm check`、`pnpm build`、Rust fmt/clippy/test 和核心 E2E 通过。
