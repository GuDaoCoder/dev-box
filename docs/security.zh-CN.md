# DevBox 安全说明

DevBox 把本地 ZIP 和插件代码视为不可信输入。Rust Host 独立完成路径、结构、大小、兼容性、checksum、签名和权限检查，前端提示不能代替这些校验。

## 已实现边界

- 只允许选择 `.zip`，拒绝绝对路径、父目录、反斜杠、重复路径和符号链接。
- 限制归档、展开、单文件、文件数和压缩比，降低 ZIP 炸弹风险。
- 签名包校验全部文件的 SHA-256 和 Ed25519；签名文件缺失一半时直接拒绝。
- 未签名包可安装，但确认页和已安装列表持续警告，用户必须自行判断来源。
- 插件 WebView 身份由 Host 绑定，调用时核对窗口、插件 ID、版本、密钥、授权和必要的用户手势。
- 插件资源使用禁止网络、对象、base URI 和表单提交的 CSP，并返回 `nosniff`。
- 插件崩溃或资源连续加载失败时可回退上一版本或停用。

## 用户责任

未签名不等于恶意，但发布者身份和内容完整性不可验证。仅安装信任来源的 ZIP，安装前核对权限，避免把密码、令牌、私钥或生产数据交给未知插件。发现异常时先停用或卸载插件，并保留 ZIP 的 SHA-256 供排查。

## 当前限制

- CI 产物尚未配置正式代码签名、Windows 信誉、Apple 公证或 Linux 仓库签名。
- 插件签名只有在发布者公钥已进入 Host 信任库时才显示为已验证，否则按未签名处理。
- 目前没有在线撤销服务或自动安全更新；插件更新由用户再次选择 ZIP。

安全回归由 `pnpm security:check` 和 Rust 测试覆盖；完整发布检查使用 `pnpm check:release`。
