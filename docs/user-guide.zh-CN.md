# DevBox 用户指南

## 安装与启动

从项目发布流程下载与你系统匹配的产物：macOS 使用 DMG，Windows 使用 MSI 或安装程序，Linux 使用 AppImage、DEB 或 RPM。当前产物未配置商业代码签名或 Apple 公证，系统可能显示开发版本警告；请核对下载来源后再继续。

从源码运行需要 Node.js 20.19+、pnpm 12.4、稳定版 Rust 和 Tauri 2 对应平台依赖：

```sh
corepack enable
pnpm install
pnpm tauri dev
```

如果终端提示 `command not found: pnpm`，先执行 `corepack enable`；仍不可用时执行 `corepack prepare pnpm@12.4.2 --activate`。

## 使用工作区

- 左侧一级菜单是功能分类，二级菜单是具体功能。
- 点击功能会在顶部打开 Tab；同一功能只会打开一次。
- Tab 支持拖动排序，右键可关闭当前、所有、右侧或其他 Tab。
- 键盘聚焦 Tab 后，可用左右方向键切换，Home/End 跳到首尾，Delete 关闭。
- 使用 `⌘K`（macOS）或 `Ctrl+K`（Windows/Linux）打开命令面板。
- 应用重启后不会恢复上次打开的 Tab。

## 内置工具

- JSON 工具：格式化、压缩、校验和递归排序对象键，输入上限为 2 MiB。
- 时间戳工具：转换秒、毫秒、日期和常用 IANA 时区。
- 编码转换：支持 Base64、URL 和 UTF-8 十六进制编解码。
- UUID 与哈希：批量生成 UUID v4，并计算 SHA-256、SHA-384 和 SHA-512。

所有转换都在本机完成，不会上传输入内容。

## 语言与主题

在左侧“系统 → 设置”中选择“跟随系统”“简体中文”或“English”。语言切换只在设置页提供，修改立即生效并保存在本机。深色和浅色主题也在同一页面切换。

## 安装自定义插件

1. 打开“插件 → 插件管理”。
2. 选择“添加 ZIP 插件”，再选择包含 `plugin.json` 的 ZIP。
3. 检查插件 ID、发布者、版本、签名状态和权限。
4. 未签名插件会显示安全警告；只有确认信任来源后再安装。
5. 安装后可在左侧插件声明的分类中打开功能。

插件可被启用、停用、更新、回退或卸载。卸载时可选择是否删除插件的本地数据。平台没有在线插件目录、自动下载或自动更新。

## 常见问题

- 浏览器调试模式无法选 ZIP 或运行插件：请使用 `pnpm tauri dev` 启动桌面应用。
- ZIP 被拒绝：确认扩展名为 `.zip`，根目录包含 `plugin.json` 和入口 HTML，且版本、路径、大小及权限声明符合规范。
- 插件显示“未签名”：平台允许继续安装，但无法验证发布者身份和内容完整性。
- 需要反馈问题时，请提供系统、DevBox 版本、操作步骤和完整错误信息；不要附带私钥或敏感输入。
