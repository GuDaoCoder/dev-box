# 安全说明

`java:execute` 不是操作系统级沙箱。代码由系统 JShell 以当前登录用户权限运行，可能读取或修改本机文件、访问网络、读取环境信息或启动其他进程。

安全边界：

- DevBox 校验插件身份、安装授权和一次性真实用户操作。
- 插件只能提交源码、超时和输出上限，不能指定 JShell 路径、命令行、工作目录或环境变量。
- Host 固定使用 JDK 11+、独立临时目录和独立 JShell 进程。
- 单次输入最大 64 KiB、最长 5 秒、总输出最大 256 KiB，同一插件只允许一个并发任务。
- 超时会终止 JShell 进程并清理临时目录，但代码此前产生的外部副作用无法自动撤销。

只运行自己编写或已经审查的代码。不要执行来源不明的片段，也不要把密码、令牌、私钥或生产数据写入代码。
