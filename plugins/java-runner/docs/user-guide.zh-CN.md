# Java 代码片段插件使用指南

## 安装

1. 安装 JDK 11 或更高版本，并确认系统可以运行 `jshell --version`。
2. 在 DevBox 中打开“插件管理 → 添加 ZIP 插件”。
3. 选择 `devbox.java-snippet-runner-<version>.zip`。
4. 核对插件名称、版本、SHA-256、未签名状态和 `java:execute` 权限。
5. 接受安全风险后安装，并从左侧“编程语言 → Java 代码片段”打开。

## 运行

- 输入 JShell 支持的 Java 声明、表达式或语句。
- 点击“运行”，或按 `Command/Ctrl + Enter`。
- 每次运行使用新的 JShell 会话，不会保留上次定义的变量。
- 结果区显示标准输出、错误、状态、耗时和退出码。
- 界面顶部显示当前 JDK 版本；可用语法和标准库以该版本为准。

不支持 Maven、Gradle、外部依赖、多文件项目、包结构、调试器或完整工程编译。

## 常见问题

- 提示找不到 JShell：安装 JDK 11+，重启 DevBox 后重试。界面顶部会显示实际检测到的 JDK 版本。
- 执行超时：单次代码最长运行 5 秒；检查死循环或阻塞操作。
- 输出被截断：标准输出与错误输出合计上限为 256 KiB。
- 无权执行：重新安装插件并确认授予 `java:execute`，或在插件管理中检查插件是否已启用。
