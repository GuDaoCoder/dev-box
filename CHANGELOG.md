# Changelog

All notable changes to DevBox are documented here. DevBox follows Semantic Versioning while the public Plugin API remains explicitly versioned.

## [Unreleased]

### Added

- Initial pnpm, React, Tauri and Rust workspace baseline.
- Shared formatting, linting, unit-test and end-to-end test configuration.
- Cross-platform continuous integration workflow.
- Responsive App Shell, semantic design tokens, light/dark themes and command palette.
- Simplified Chinese and English localization with persistent language settings.
- Versioned IPC contracts, Plugin SDK, static plugin registry and lifecycle manager.
- Controlled Rust command gateway and SQLite-backed revisioned settings repository.
- Foundation plugin for validating activation, Host commands and settings persistence.
- Versioned Plugin API, strict manifest schema and deterministic `.devbox-plugin` packaging CLI.
- SHA-256 and Ed25519 verification, bounded archive validation and trusted publisher storage.
- Atomic online/offline plugin installation, update, rollback, recovery, grants and uninstall flow.
- Isolated plugin WebViews with caller identity binding, CSP, ready timeout and scoped Host gateways.
- Bilingual Plugin Center with installed, official catalog and offline package workflows.
- Signed M2 fixture packages, local catalog and installer lifecycle regression coverage.
